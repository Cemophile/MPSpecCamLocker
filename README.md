# MPSpecCamLocker

A spectator camera mod for Mount & Blade II: Bannerlord.

## Features

Camera lock to players POV with F8.

Switch between spectated players using the left and right mouse buttons.

Change the camera distance using the mouse wheel.

The camera follows the position and direction of the spectated player.

Select the player you want to spectate from the menu or search them, mark them by clicking on their name and spectate.

## Controls

F8 - Toggle camera lock
M - Spectator Menu
Mouse Wheel - Change camera distance

## Installation

Build the mod and place the MPSpecCamLocker folder inside your games modules folder.
Enable the module in the launcher.
Release file will be added soon.
